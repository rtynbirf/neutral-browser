# ФУНДАМЕНТ: ЧЕЛОВЕК ПРЕВЫШЕ ВСЕГО

> «Цвет, шрифт, оформление — для человека, созданы человеком, а не людьми.
> Забота о его зрении, когнитивном и психологическом здоровье».
> Формулировка командира, 2026-09-16. Источник принципа — эталон
> «ГОЛОГРАММА v1» (`tests/fixtures/gologramma_v1.html`), разделы
> «Человек прежде всего» и «Автономен по построению».

Этот документ — не манифест, а контракт: каждый принцип либо уже несёт
машинную проверку, либо честно стоит в NOT_IMPLEMENTED с требованием,
которое будущий этап ОБЯЗАН выполнить. Принцип без механизма = шум;
здесь шум не разводится.

## 1. Человек — принципал. Машина не трактует

Движок рендерит и честно считает — не интерпретирует за человека.
Это уже встроено в архитектуру и проверено гейтом:

- юзер-принципипал: capability выдаётся от имени человека
  (`POLICY_BROKER_MODEL=PASS`, `tests/architecture.py`);
- движок не «улучшает» контент: неподдержанное считается в открытых
  счётчиках (`STYLE_ERRORS`, `LAYOUT_ERRORS`, `PAINT_ERRORS`), а не
  маскируется под поддержанное;
- текст самодостаточен: сначала читаем содержание, потом смотрим
  оболочку (урок экзамена по GOLOGRAMMA_v1, worklog Task 48→49).

## 2. Приватность построением, а не обещанием

- ноль сетевых запросов без явной команды человека: единственный
  `TcpStream::connect` в `src/network.rs`, за брокером
  (`STAGE2_STRUCTURE=PASS`) — следить нечем физически;
- ноль телеметрии, ноль куков, ноль облака, ноль аккаунтов: движку
  нечего отправлять — прецедент Мюнхена 01.2022 (Google Fonts → GDPR)
  в архитектуре исключён классом, а не политикой;
- `--dom-file` работает с выключенной сетью: офлайн — режим первого
  класса, сеть — бонус, не условие выживания.

## 3. Автономность = один артефакт

- вся цепочка URL→…→PAINT→PNG выполняется локально, ноль зависимостей
  (Cargo.lock = ровно 1 пакет — доказательство на уровне lockfile);
- настройки человека — файлы человека на его устройстве; ничего
  «не улетает» по построению: механизма отправки в движке нет.

## 4. Здоровье: замороженные требования к рендерингу

Когда этапы текста и рендеринга дойдут до очереди, они обязаны
выполнить нормы эталона — это требования к фундаменту, не украшения:

| Норма | Значение | Статус в движке |
|---|---|---|
| Мигание | 0 Гц без явного запроса человека; ≤3 Гц предел (WCAG 2.3.1) | VERIFIED построением: PAINT статичен, анимаций в движке нет |
| Навязанное движение | нет (prefers-reduced-motion уважать всегда) | VERIFIED построением: движения нет |
| Контраст текста | WCAG 2.2 ≥ 4.5:1, второй контур APCA Lc ≥ 75 | NOT_IMPLEMENTED: движок обязан УМЕТЬ СЧИТАТЬ контраст, чтобы гарантировать норму, а не надеяться |
| Межстрочный интервал | ≥ 1.5 | NOT_IMPLEMENTED (line boxes — этап 9) |
| Длина строки | 50–75 знаков (Baymard) | NOT_IMPLEMENTED (текст не раскладывается) |
| Тач-цели | ≥ 44 px (HIG/Material; минимум WCAG 2.5.8 — 24 px) | NOT_IMPLEMENTED (интерактивных целей в движке нет) |
| Цвет не единственный носитель смысла | дублирование текстом/числом | требование ко всем будущим дампам и выводам движка |
| Шрифт чтения | кириллица с расчётом на разборчивость (прецедент Golos Text) | NOT_IMPLEMENTED: шрифтов в движке нет |

Правило этапа: норма здоровья вводится ТОГДА ЖЕ, когда вводится
механизм, который может её нарушить. Этап, добавляющий текст, обязан
добавить и замер межстрочного/длины строки; этап, добавляющий цвет
фона по умолчанию, обязан добавить расчёт контраста.

## 5. Честность = забота

Осведомлённый дурак лучше неосведомлённого умника. Всё, что движок
не умеет, лежит в README/NOT_IMPLEMENTED открытым текстом и
экспонируется счётчиками — человек видит разрыв своими глазами,
а не верит движку на слово. Шум не удаляется: удаление = потеря
доказательства.
